# zoopass → Virtual Automotive Test Lab

車載器テスト設計ワークショップ「**Virtual Automotive Test Lab**」用の、車載インフォテインメント **VATL-100**（架空）のエミュレーター。
参加者は仕様書を読んでテストケースを設計し、ブラウザ上のエミュレーターで実行して不具合を見つける。

> 以前の ZooPass（入園予約アプリ）は、このフォルダを書き換えて作った。元のコードは Git の履歴（コミット `0fba4fc`）に残っている。

| 項目 | 値 |
| --- | --- |
| Firebase プロジェクト | `security-portal-c3fd4`（portal と同じプロジェクトの別サイト） |
| 使用サービス | Hosting のみ（サイト `vatl-lab`） |
| 画面 | `/` エミュレーター、`/spec` 仕様書 |
| 公開URL | https://vatl-lab.web.app |

## 構成

```
frontend/public/
  index.html       エミュレーター（車載ディスプレイ・ステアリングスイッチ・拡張コントロール・操作ログ）
  spec.html        参加者向け仕様書（要求ID つき）
  js/unit.js       VATL-100 の動作モデル（DOM 非依存。テストからも読み込む）
  js/app.js        画面表示と入力の受け渡し
  css/style.css
tests/
  unit.test.js     仕様どおりに動く部分のテスト（node --test）
instructor/        講師用の解答（.gitignore 済み。GitHub には含めない）
```

## エミュレーターの機能

Android Automotive OS のエミュレーターに近い形（横長 16:9 の車載ディスプレイ＋拡張コントロール）。見た目は独自デザイン。

| 機能 | 内容 | 仕様書の要求ID |
| --- | --- | --- |
| 電源 | イグニッション ON/OFF、起動、状態の記憶と復元 | PWR-01〜06 |
| 音量 | ステアリングスイッチで 0〜30、MUTE | VOL-01〜04 |
| メディア | ラジオ（FM 76.0〜95.0 MHz）/ Bluetooth オーディオ / USB、曲送り・再生/一時停止 | SRC-01〜08 |
| 走行中の操作制限 | 車速 5 km/h 以上で地図（目的地検索）・設定を禁止 | DRV-01〜04 |
| 地図 | 目的地検索（キーワード 1〜20 文字、部分一致）、ルート案内 | NAV-01〜06 |
| 後退 | ギア R でバックカメラ優先表示、音量制限 | REV-01〜04 |
| 電話 | 着信・応答・拒否・終話、履歴 | TEL-01〜07 |
| エアコン | 画面下のエアコンバー：両席温度、SYNC、風量、A/C、デフロスター、シートヒーター | HVAC-01〜07 |
| 設定・表示 | 画面の明るさ 1〜5、テーマ（自動/ライト/ダーク） | SET-01〜02 |
| 車両情報・通知 | 外気温、燃料残量警告、ドア開警告、通知一覧 | VEH-01〜04 |

右側の「拡張コントロール」（車両・環境・センサー・接続・状態のタブ）で、イグニッション・車速・ギア・昼夜・外気温・燃料・ドア・USB・Bluetooth・着信を変えられる。「状態」タブで内部の値を確認できる。
画面下の「操作ログ」は、テスト実行の証跡としてコピーできる。

**ワークショップ用に、意図的な不具合をいくつか仕込んである。** 内容は `instructor/answer-key.md`（非公開）を参照。
公開リポジトリと配信される JS からはコードを読めるので、参加者にはソースを見ずに仕様書とエミュレーターだけで取り組んでもらう。

## ローカル実行

```powershell
firebase emulators:start --only hosting
```

http://localhost:5000 を開く。ビルドは不要。

## テスト

```powershell
cd tests
npm test                       # 仕様どおりに動く部分のテスト
cd ..
node --test instructor/        # 講師用：仕込んだ不具合が残っているかの確認
```

## デプロイ

```powershell
firebase deploy --only hosting
```
